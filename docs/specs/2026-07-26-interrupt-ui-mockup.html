Anti-pattern 现状 · 不要再这样 避免
Service Notice

MessageAbortedError: Aborted

交互要点
1. 点停止后立刻进入 Stopping：停按钮变「停止中 + spinner」，不可再点；线程内虚线条提示「正在停止回复…」——覆盖 cancel→Idle 的不可避免延迟。
2. Idle / flush 完成后：去掉 loading，落一条中性 已停止 提示（纸面卡片 + muted 标题），禁止 Error / Service Notice / 红底 / MessageAbortedError 字样。
3. Coral 只用在「可点的停止」按钮上；loading / 完成态全部走 ink / panel / muted。
4. 文案可微调：「你已打断本次回复」或「回复已停止」；动作只保留「知道了」（等同 dismiss）。
