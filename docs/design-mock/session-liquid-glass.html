会话列表 · 液态玻璃选中浮层

一个共享的玻璃层贴在列表底层，切换 session 时只改 translateY + height， 浮层「顺」过去，而不是每张卡自己亮灭。点列表或用下方按钮试效果。

推荐默认 Glass；Gooey 靠 SVG filter，落地成本更高
Pinned · 1

可行性

  • 可行 — 单层绝对定位 indicator + FLIP/transform，和 Soft Comfort 现有「白卡浮层」兼容。
  • React 落地：列表 ref 量选中行的 offsetTop/offsetHeight，切 activeSessionId 时更新玻璃层；滚动时同步。
  • 需要 backdrop-filter（桌面 Chromium/WebKit 都 OK；列表底色要透一点才看得出玻璃）。
  • 注意 — 展开 ⋯ dock / 高度变化时要重测；虚拟列表要改成基于可视坐标。
  • Gooey 滤镜好看但脏边/文字模糊风险大，建议先上 Glass。

推荐动效参数

  • 时长 ~400ms · cubic-bezier(0.22, 1, 0.36, 1)
  • 移动中略放大圆角 / 加深阴影（本页 .moving）
  • 行本身不再各自 bg-paper shadow，只留玻璃层当选中态
