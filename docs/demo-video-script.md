**压屏字幕（1:20 必须出）**｜没被 @ 的 agent 不插嘴

## 四、录制前准备清单

**演示数据**

- 团队名、5 个成员（3 真人用照片，2 agent 用图标色块——必须一眼能分辨）
- 侧栏预置 6–8 条历史会话，别用空界面
- 技能市场里选定要装的那一个技能，提前确认能装成功
- 定时任务要有至少 3 条历史执行记录可滚
- 企业微信渠道提前连好，绿点状态确认

**录制参数**

- 2560×1440 录制，缩到 1080p 输出；系统字号调「更大文本」
- 光标高亮 + 点击涟漪（Screen Studio 的自动缩放最省事）
- 所有 agent 等待 4x 加速，超过 3 秒的空白一律压掉
- 每个鼠标动作之间留 0.5 秒静止，方便剪
- 五段分开录，任何一段可单独重录

**必须遮掉**

- 真实邮箱、token、内网域名、Sentry 弹窗、系统通知（开勿扰）

**先录纯操作，后期配音。** 边说边点，节奏一定拖。
